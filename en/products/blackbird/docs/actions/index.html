Documentation / Everyday use

Find and run Actions

Search, filter, arrange, and run the tasks installed in Blackbird.

Based on 0.8.3-alpha.4 development documentation. Updated 2026-09-22. Some features may differ from your installed version.

Actions perform individual tasks, such as opening a project, building an application, or collecting logs. Use the Actions page to find a task and run it, or add it to your queue for later.

Try your first Action

System Information is a simple way to try Blackbird. It shows information about your computer without requiring a project or connected device.

  1. Select Actions in the sidebar.
  2. Select Clear filters if any filters are active.
  3. Search for System Information.
  4. Select Run on that Action.

When it finishes, a result window shows your operating system, PowerShell version, and ADB availability. You can close the window when you're done.

If ADB says Not found, that does not mean this Action failed. ADB is used for Android tasks; you don't need it to run System Information.

Find the Action you need

Type in the search field to narrow the list. You can search by an Action's name or choose a suggested filter, such as a tag, Bundle: Utilities, or Creator: Incogent.

A bundle is a collection of related packages. Bundle filters are useful when you want to see the Actions installed from one collection, such as Android or Utilities.

Selected filters appear as chips below the search field:

  • Select a chip's × to remove that filter.
  • Use Match: All to require every selected filter.
  • Use Match: Any to accept any selected filter.
  • Select Clear filters to reset the search and filters.

Choose the project and device

Before running an Action that works with a project or device, check the selectors at the top of the window.

Project selects the project the Action will use. For example, a build Action needs the correct project's configuration.

Device selects the target device. This PC means the computer running Blackbird. For an Action that operates on a connected device, select that device instead.

Not every Action needs both selections. Blackbird asks for required settings before starting when they haven't been configured yet. Review those settings, then continue with the run. You may also be asked for choices that apply only to this run.

Run now or queue for later

Select Run to start an Action. If Blackbird asks you to review settings or confirm the operation, complete that prompt to continue.

Select Queue to add an Action to the queue without running it immediately. This is useful when you want to prepare several tasks before starting them.

While work is running, progress appears below Output. Expand Output to read the Action's messages. If several operations are running, expand the progress group to see their individual bars.

When an Action finishes, its result window reports the outcome. If it fails, follow the correction shown there. When available, Configure Setting takes you to the setting that needs attention. Output provides additional detail.

Arrange the list

Open the view-options button beside the Match controls. Its label reflects your current layout and sorting choices.

  • Choose Cards or List for the layout you prefer.
  • Sort alphabetically, by recently used Actions, or by recently added Actions.
  • Choose Group: Bundle, Group: First tag, or Group: None. Bundle grouping is the default.

Grouping changes how results are arranged. Filters determine which Actions appear.

Can't find an Action?

Try these checks:

  1. Select Clear filters to remove a search or filter that might hide it.
  2. Open view options and check Hide actions incompatible with selected device. If enabled, choose a compatible device or turn the option off to see more Actions.
  3. Open Settings > Packages and check whether the package containing the Action is installed.

If the Action appears but won't start, read the message Blackbird displays and check that the intended project and device are selected.
