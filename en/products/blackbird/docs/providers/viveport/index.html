Upload to Viveport PC

Set up Viveport PC for the Upload Build Action.

Based on 0.8.3-alpha.4 development documentation. Updated 2026-09-22. Some features may differ from your installed version.

Tool and account setup

Use the Viveport Developer Console and its authorized distribution resources to obtain the uploader and identify the target application and organization. This adapter is for PC builds.

Set Viveport uploader executable, Viveport account email, and secret password. Configure PC build directory, Archive cache location, App ID, and Organization ID. Use a writable cache location with room for the upload preparation; do not point it at a folder containing unrelated files you need to preserve as generated output.

Supply the Build version for the run. Review the app/organization pairing and source build before leaving validation-only mode. The Action prepares the upload's archive/metadata as needed; a local validation result does not prove the remote service will accept the build.

After upload, inspect the correct application's build listing in the developer console. Missing executable/support files, insufficient staging space, invalid credentials, or access to the wrong organization need distinct corrections. Store review/public availability remains a separate provider process.

Validate, then upload

  1. Select this provider in an Upload Build publishing profile and save the fields described above.
  2. Run Validate without uploading and correct the reported local issues.
  3. Turn validation-only off only when you intend a real transfer; confirm the destination and any live/draft options.
  4. Read the result and verify the provider dashboard before retrying or distributing the build.

Tool compatibility and official help

Use the provider’s official documentation and tool access. Source/configuration review: 2026-09-22. A minimum certified uploader version is not established for this guide. Record the actual tool version used during your test; do not assume every current or future CLI version is compatible. Vendor access may require sign-in. This page is not a claim of a completed live upload test.
