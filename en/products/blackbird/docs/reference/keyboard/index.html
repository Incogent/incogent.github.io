Keyboard and mouse controls

Navigate Blackbird and understand selection versus editing.

Based on 0.8.3-alpha.4 development documentation. Updated 2026-09-22. Some features may differ from your installed version.

Open Settings > Keyboard Controls, or press F1 outside an editor/menu/dialog/tutorial, for the in-app reference.

Common shortcuts

KeyAction
Ctrl+1 / Ctrl+2Open Project / Device selector
Ctrl+FSelect automation search; Enter begins editing
Ctrl+TEdit automation search and open tag suggestions
TabToggle Queue outside text editing
BacktickToggle Output outside text editing
Shift+TabExpand/collapse Navigation outside text editing
Alt+Up / Alt+DownPrevious/next automation filter
Mouse Back / ForwardRestore previous navigation/filter views

Selection is not editing

Arrow navigation selects controls. Enter activates the selected control or begins editing a selected field. Clicking an editable field begins editing directly. A selected field does not necessarily accept typing or paste until editing begins.

Menus, dropdowns, dialogs, tutorials, and active editors have their own key handling. Native editor keys take precedence where appropriate; do not assume every global shortcut applies while typing.

Escape

Escape dismisses the current menu, editing state, or dismissible dialog layer. In an active editor it clears the field and leaves editing mode. On selected non-editing automation search it clears tags while preserving search text. It does not generally stop an Action or quit Blackbird. Use the explicit Stop control for cancellation.

The in-app reference is the best place to check the complete bindings for the version you are using. Keyboard selection can reveal disabled controls for inspection, but cannot activate them.
