Setting definition reference

Look up the fields that describe an Action input.

Based on 0.8.3-alpha.4 development documentation. Updated 2026-09-22. Some features may differ from your installed version.

Identity and value

FieldMeaning
idCanonical namespace.key used by scripts, storage, conditions, and sharing
label / descriptionFriendly name and guidance in the UI
typetext, integer, number, boolean, choice, file, folder, secret, or array
scopeproject, application, or run
requiredValue must be provided while the field is applicable
defaultFallback value; prohibited for secrets
rememberRunValueWhether a non-secret run value can be suggested next time

Options and structure

FieldMeaning
choicesAllowed static options for a Choice field
allowCustomChoiceAllows a typed choice as well as suggestions
valueModesingle, or supported project namedOptions
profileGroups related project fields into an Action-owned preset
itemFields / itemLabelArray record schema and UI item name
visibleWhen / enabledWhenConditions referencing full parameter IDs
section / advancedPresentation grouping and advanced-field placement

File constraints must agree when sharing a setting identity. Array field keys are local to the array record. Declare controlling fields before dependent fields, and test each applicable condition.

Dynamic choices

A choice provider uses a package-relative script with the platform runner and returns a JSON string array on standard output. Keep diagnostics out of that output. Use it only when choices genuinely depend on the environment; static choices are easier to inspect and test.

Compatibility

When reusing a canonical ID, match its scope, type, value mode, choices, and relevant path constraints. The editor offers reusable definitions to reduce accidental drift. Changing a contract can invalidate captured Queue/Workflow values; review them rather than assuming defaults repair the change.

For the creation workflow and examples, use the authoring guides. This reference describes parameter definitions, not arbitrary additional top-level project configuration properties.
