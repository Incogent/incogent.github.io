Set up a SteamOS device

Pair a development host and verify SteamOS discovery.

Based on 0.8.3-alpha.4 development documentation. Updated 2026-09-22. Some features may differ from your installed version.

Prepare and pair the device

Follow Valve's development-device setup and pairing instructions for your supported device. Complete pairing with this development computer before expecting Blackbird's SSH-based operations to work. Keep the device and computer on a network that permits the connection.

Blackbird uses the paired development-host key and verifies the connection. Running the Devkit Client GUI is not required for every later operation once pairing is available. A host answering on the network is not sufficient evidence that authentication succeeded.

Discover it in Blackbird

  1. Enable the relevant development service on the device.
  2. Refresh the Device selector in Blackbird.
  3. Select the verified SteamOS target.
  4. Check Output for scan warnings if it does not appear.

If local host-name discovery fails, review the configured SteamOS host list in Settings and use the correct reachable host address. Do not use an Android serial in place of a SteamOS host.

Choose the right target and build

Steam Deck, Steam Machine, and Steam Frame retain their supported device kinds in the current app. Actions decide which kinds they support. A Frame's Lepton Android endpoint is separate from its native SteamOS target; Lepton does not need to be running to verify the native connection.

Configure the build profile and runtime for the artifact you are installing. A Windows, Linux, or Android build needs an appropriate runtime and target; successful file transfer alone does not prove it can launch.
