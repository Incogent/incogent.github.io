Documentation / Troubleshooting

An Action is missing or will not run

Work through the likely causes and preserve useful diagnostics.

Based on 0.8.3-alpha.4 development documentation. Updated 2026-09-22. Some features may differ from your installed version.

Check in this order

  1. Clear the search and selected filter chips. Check Favorites, Recent, and pinned views before assuming the Action was removed.
  2. Check the selected device and Hide actions incompatible with selected device. An Action can be installed but unavailable for that target.
  3. Open Settings > Packages and confirm the Action and required support libraries are installed.
  4. Select the intended project and follow Configure Action for missing settings. When a result offers Configure Setting, use it to reach the exact field.
  5. If a package issue is reported, correct the manifest/dependency issue or reinstall the intended official package through its supported flow. Do not edit internal catalog records.

Before retrying

When the Action becomes available, test it with an input whose effects you understand. Another active run or queued scheduled work can delay execution; do not repeatedly click Run to force concurrency.

If it still fails

Capture the exact error, relevant app/package/tool versions, and the smallest steps that reproduce it. Review the log for private information before sending it. Use Report a problem for a complete report checklist.
