Documentation / Troubleshooting

Blackbird will not start or activate

Work through the likely causes and preserve useful diagnostics.

Based on 0.8.3-alpha.4 development documentation. Updated 2026-09-22. Some features may differ from your installed version.

Check in this order

  1. Record the exact startup or activation error and the app version. Distinguish a configuration error from a license or update failure.
  2. If Blackbird is already open or minimized, activate that instance rather than expecting a second independent library session.
  3. For a reported locked file, close the process using it when identified. For an invalid configuration, preserve the file and use the reported correction or support guidance.
  4. For activation, confirm the intended issued information and any required network access. Do not include the license or redemption code in a public report.
  5. If the problem followed an update, report the old/new versions and whether it occurred before or after the main window appeared.

Before retrying

Do not delete the package library, project configuration, or license state as a general reset procedure. An application reinstall does not necessarily fix malformed project data and can obscure the original problem.

If it still fails

Capture the exact error, relevant app/package/tool versions, and the smallest steps that reproduce it. Review the log for private information before sending it. Use Report a problem for a complete report checklist.
