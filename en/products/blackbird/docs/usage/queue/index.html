Prepare and run a queue

Arrange several Actions and review their saved settings before execution.

Based on 0.8.3-alpha.4 development documentation. Updated 2026-09-22. Some features may differ from your installed version.

Prepare the work

  1. Find an Action and select Queue.
  2. Complete any requested configuration. Repeat for the other tasks you want to run.
  3. Open the Queue panel and arrange items in their intended order.
  4. Edit an item to review its project, parameter values, profile, and device target. Remove items you no longer need.
  5. Select the queue's Run control when the sequence is ready.

A useful sequence might build a project, deploy its output, and launch it. Each Action must be configured correctly; placing Actions together does not automatically pass arbitrary script variables between them. Use shared settings or explicit files when tasks need the same information.

Saved settings and device choice

Queue items capture resolved configuration. Later changes to package defaults or a project's profile do not silently replace that saved configuration. After changing a setting, edit the item if you want it to use the new value.

Current device is different: it is resolved when the item begins. Pin a target in the item editor when it must use one specific device. A library or parameter change that makes a saved item invalid requires review before execution.

Pause, stop, and inspect

Pause after current action lets the running Action finish before the queue pauses. Stop requests cancellation of active work; it does not undo completed file changes, installs, or uploads. Review results before restarting a partially completed sequence.

Follow progress below Output, and use the completion result and History to inspect what ran. If a task fails, address the reported cause and review remaining work rather than assuming the sequence completed.

Reuse the sequence

Save the queue as a Workflow when you want to load or schedule it again. A Workflow is a saved sequence, while the visible queue is your current working copy.
